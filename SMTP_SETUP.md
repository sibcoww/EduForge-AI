# Сохранение входа и SMTP

Вход по паролю и через Google сохраняется в браузере на 30 дней. Cookie — HttpOnly, с датой истечения и Max-Age. В production используется Secure. Токен не записывается в localStorage. После обновления войдите заново один раз: старые cookie сохраняют прежний срок 8 часов. Выход и смена пароля отзывают сессии через SecurityStamp.

Срок задаётся `Auth__SessionDays` в `.local/settings.json`: по умолчанию 30 дней, допустимый диапазон 1–90. Не использовать режим инкогнито и автоматическую очистку cookie, если хотите сохранять вход после закрытия браузера.

## Gmail для восстановления пароля

В `.local/settings.json` подготовлены настройки Gmail для администратора. Осталось заполнить `Smtp__Password` паролем приложения Google.

1. Откройте Google-аккаунт отправителя. Если отправитель другой, измените `Smtp__From` и `Smtp__User` на его адрес.
2. Включите [двухэтапную аутентификацию](https://myaccount.google.com/signinoptions/two-step-verification).
3. Откройте [Пароли приложений](https://myaccount.google.com/apppasswords) и создайте пароль для EduForge AI. [Пояснение Google](https://support.google.com/accounts/answer/185833?hl=ru).
4. Вставьте созданный пароль только в локальное поле `Smtp__Password`. Обычный пароль Google сюда не подходит. Пробелы в пароле приложения Gmail сервис убирает автоматически.
5. Сохраните файл. При локальном запуске настройки перечитываются автоматически; при использовании переменных окружения нужен перезапуск API.
6. На сайте откройте «Забыли пароль?» и укажите адрес существующего аккаунта с паролем. Проверьте входящие письма и спам, откройте ссылку и установите новый пароль. Ссылка действует 30 минут и используется один раз; старые сессии завершаются.

Google-аккаунты без локального пароля используют «Войти через Google»; SMTP не меняет пароль самого Google-аккаунта. Если пункта «Пароли приложений» нет, ограничения аккаунта могут не разрешать этот способ — можно выбрать другой SMTP-провайдер.

Текущая конфигурация: `smtp.gmail.com`, порт `587`, STARTTLS. Реальная доставка проверяется после заполнения пароля приложения. Для другого сервера задайте Host, Port, From, User и Password; отправка использует STARTTLS, а не implicit TLS на порту 465.
