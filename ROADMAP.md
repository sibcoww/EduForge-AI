# План развития EduForge AI

Обновлено 18 ноября 2026 года. Выполненные пункты отмечены `[x]`; незавершённые проверки и отложенные идеи — `[ ]`. Инструкции и результаты технических проверок: [TESTING.md](TESTING.md).

Тема диплома: «Интеллектуальная система автоматической генерации учебных и тестовых материалов».

## Материалы и редактор

- [x] Создание, редактирование в отдельном окне и удаление материалов.
- [x] Структурированная AI-генерация по теме: заголовки, объяснения, списки и примеры.
- [x] Загрузка PDF с текстовым слоем, DOCX, TXT и Markdown; выбор разделов для генерации, ссылки на источники и проверка цитат.
- [x] Визуальный редактор TipTap, таблицы, ссылки, форматирование текста и корректное отображение Markdown-выделения.
- [x] Блоки кода с подсветкой, выбором языка и копированием; сохранение операторов и отступов.
- [x] Загрузка, вставка из буфера и перетаскивание изображений; подписи, размер, расположение и увеличение.
- [x] Красные места для недостающих скриншотов, включая предложения AI в инструкциях по программам.
- [x] Редактор скриншотов: стрелки, круги/овалы и прямоугольники пяти цветов, номера и пояснения.
- [x] Сохранение исходника и отдельных выделений для повторного редактирования; управление координатами без перетаскивания.
- [x] Подписи вручную, из пояснений или через AI по изображению и выделениям.
- [x] AI-иллюстрации отдельным действием с предпросмотром; нужен доступ к настроенной модели изображений.

## Тесты и контролируемая генерация

- [x] Создание, редактирование и удаление тестов; пять типов вопросов.
- [x] Максимальный балл теста, распределение баллов по вопросам и перемешивание вариантов ответа.
- [x] Генерация по материалу с передачей уровня, языка и сохранённых педагогических пожеланий, включая возраст.
- [x] Дополнительные пожелания к текущей генерации теста.
- [x] Предложение учебных целей AI, ручная правка и обязательное подтверждение преподавателем.
- [x] Привязка вопросов к версии и блокам урока, дословным цитатам и объяснению ответа.
- [x] Основания ответов свёрнуты и раскрываются по нажатию; статус проверки виден сразу.
- [x] Матрица покрытия целей, число проверенных вопросов и баллы по целям.
- [x] Пересмотр затронутых вопросов после изменения урока, сравнение текста и выборочная перегенерация.
- [x] Проверка готовности контролируемого теста перед публикацией и созданием сессии.
- [x] Эвристические предупреждения о повторах вопросов, похожих вариантах и отсутствующих эталонах.
- [x] Очистка Markdown-звёздочек в AI-вопросах, вариантах, эталонах и объяснениях без порчи кода и точных цитат.
- [x] Неизменяемые снимки вопросов проведённых сессий; правки и удаление исходного теста не пересчитывают прежние результаты.

Цитаты и покрытие помогают проверять тест, но не доказывают логическую правильность ответа или усвоение темы. Проверка преподавателя остаётся обязательной для контролируемого режима. Старые и ручные тесты поддерживают обычный режим.

## Группы и сессии

- [x] Группы, состав студентов и ручное редактирование записей.
- [x] Приглашение по ссылке: имя и фамилия без обязательного аккаунта студента.
- [x] Подтверждение записей, обработка дублей, отзыв и замена приглашения.
- [x] Сессии с кодом подключения, таймером, автосохранением ответов и результатами.
- [x] Перемешивание вопросов/вариантов и журнал ухода со вкладки, выхода из полноэкранного режима и разрывов соединения.

События — сигналы для преподавателя, а не автоматическое доказательство списывания. Второй телефон сайт не обнаруживает.

## Профиль и аккаунты

- [x] Вход по email/паролю и Google, сохранение входа в браузере.
- [x] Восстановление пароля через SMTP при настроенном отправителе.
- [x] Профиль: имя, аватар, описание, необязательные возраст, страна и город.
- [x] Дисциплины метками, поиск, связанные рекомендации и собственные дисциплины.
- [x] Рекомендации общей библиотеки по дисциплинам с возможностью просмотреть всё.
- [x] Администратор: управление аккаунтами и удаление с проверкой связанных данных.

## Библиотека, доступ и модерация

- [x] Переключение материалов/тестов, отдельная публикация тестов, копирование материала с его публичными тестами.
- [x] Ручная модерация администратором: ожидание, одобрение, отклонение с причиной.
- [x] Частный доступ, доступ по ссылке только вошедшим преподавателям и публичная библиотека после модерации.
- [x] Просмотр теста по ссылке без ключей ответов, оснований и частной истории AI.
- [x] Отзыв старой ссылки при закрытии доступа; защита от устаревших настроек и решений модерации.
- [x] Проверка доступа к изображениям; исходники скриншотов и редакторские пометки не передаются в общий просмотр.
- [x] Отметка «Уже добавлено», связь личной копии с версией оригинала.
- [x] Предложение обновить копию, сравнение версий и сохранение локальных правок отдельной версией.
- [x] Удаление материалов/тестов с закрытием публикаций и ссылок, сохранением сессий и чужих копий.

При удалении материала связанные тесты сохраняются без исходного урока и контроля оснований; подтверждение объясняет это до удаления. Режимы доступа используют сохранённые снимки: изменения нужно отдельно открыть по ссылке или отправить на модерацию. Копии, созданные до внедрения связи с оригиналом, автоматически не связываются.
