# Небольшая HTML-страница

Авторский фрагмент для технического пилота EduForge AI.

В примере h1 содержит основной заголовок страницы. Элемент p задаёт абзац текста. Элемент a создаёт ссылку, адрес перехода задаёт атрибут href.

```html
<h1>Моя учебная страница</h1>
<p>Здесь опубликован пример задания.</p>
<a href="https://example.com">Учебная ссылка</a>
```

Видимый текст ссылки — «Учебная ссылка». Значение href — адрес https://example.com.
В этом задании нужно сохранить один основной заголовок, один абзац и одну ссылку. Проверка состоит в открытии страницы в браузере и сопоставлении структуры с этими требованиями.
