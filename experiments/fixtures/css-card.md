# Оформление карточки CSS

Авторский фрагмент для технического пилота EduForge AI.

Селектор .card выбирает элементы с классом card. Свойство padding задаёт внутренний отступ между содержимым и границей. Свойство margin задаёт внешний отступ.

```css
.card {
    padding: 16px;
    margin: 12px;
    background: white;
}
```

В этом примере внутренний отступ равен 16 пикселям, внешний — 12 пикселям. Увеличение padding расширяет пространство внутри карточки вокруг содержимого. Увеличение margin изменяет внешний отступ карточки.
Для проверки задания преподаватель сопоставляет значения свойств с требованиями и смотрит расположение карточки в браузере.
