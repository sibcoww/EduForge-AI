# Циклы Python

Авторский фрагмент для технического пилота EduForge AI. Не является результатом педагогического эксперимента.

Цикл for перебирает элементы последовательности. Переменная цикла получает очередной элемент на каждой итерации.
Функция range(3) задаёт числа 0, 1, 2. Правая граница не включается.

```python
for number in range(3):
    print(number)
print("Готово")
```

В примере print(number) входит в тело цикла благодаря отступу и выполняется три раза. Последний print расположен без отступа и выполняется один раз после цикла.
Если последний print сдвинуть внутрь тела цикла, сообщение будет выводиться на каждой итерации.
