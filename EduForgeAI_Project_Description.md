# EduForge AI

## 1. Общая информация

**EduForge AI** — интеллектуальная веб-платформа для преподавателей, предназначенная для создания учебных материалов, тестов и заданий с помощью искусственного интеллекта, проведения тестирования студентов, анализа результатов и публикации готовых материалов в общей библиотеке.

Основная идея проекта — объединить в одной системе полный цикл работы преподавателя:

```text
Создание материала
        ↓
Проведение занятия
        ↓
Создание теста или задания по материалу
        ↓
Проведение тестирования во время занятия
        ↓
Получение результатов
        ↓
Анализ результатов
        ↓
Создание дополнительных материалов по проблемным темам
```

Искусственный интеллект выступает помощником преподавателя, но не заменяет его. Преподаватель всегда может отредактировать, удалить или дополнить созданный AI-контент.

---

## 2. Цель проекта

Создать современную образовательную веб-платформу, которая позволит преподавателям:

- создавать учебные материалы с помощью AI;
- создавать тесты и задания по конкретному учебному материалу;
- редактировать AI-сгенерированный контент;
- сохранять материалы в личной библиотеке;
- публиковать материалы в общей библиотеке;
- создавать учебные группы;
- проводить тестирование студентов во время занятий;
- получать результаты студентов в реальном времени;
- анализировать результаты группы;
- экспортировать материалы в PDF и DOCX;
- использовать AI для анализа результатов и создания дополнительных материалов.

---

## 3. Основная проблема

Преподаватель регулярно тратит много времени на:

- подготовку конспектов;
- составление тестов;
- подготовку практических заданий;
- проверку результатов;
- поиск готовых материалов;
- анализ ошибок студентов;
- подготовку повторных объяснений по сложным темам.

EduForge AI должен сократить время на эти задачи и объединить их в одной системе.

## 4. Пользователи системы

### 4.1. Преподаватель

Преподаватель является основным пользователем платформы и имеет полноценный аккаунт.

Способы авторизации:

- Google OAuth 2.0;
- Email + пароль.

В дальнейшем можно добавить Microsoft Account и другие OAuth-провайдеры.

Преподаватель может:

- создавать материалы;
- использовать AI;
- редактировать материалы;
- создавать группы;
- добавлять студентов;
- создавать тесты;
- создавать задания;
- запускать тестовые сессии;
- отслеживать прохождение тестов;
- просматривать результаты;
- публиковать материалы;
- использовать материалы других преподавателей;
- экспортировать документы.

### 4.2. Студент

Студенту **не требуется отдельная регистрация и аккаунт**.

Студент хранится в системе как участник определённой группы.

Пример:

```text
Группа: Python-24

1. Айтбаев Данияр
2. Ахметова Алина
3. Жумабаев Али
4. Садыков Арман
```

Студент подключается только к конкретной тестовой сессии или заданию.

Способы подключения:

- по уникальной ссылке;
- по коду подключения.

После подключения студент выбирает себя из списка своей группы. В будущем можно добавить PIN-код для дополнительной проверки личности.

### 4.3. Администратор

Администратор управляет системой.

Возможности:

- просмотр пользователей;
- блокировка аккаунтов;
- модерация опубликованных материалов;
- просмотр статистики;
- управление жалобами;
- удаление запрещённого или некорректного контента.

## 6. Генерация материала с помощью AI

Преподаватель открывает раздел создания материала и задаёт параметры:

```text
Предмет: Python
Тема: Цикл for
Тип: Учебный материал
Уровень: Начинающий
Язык: Русский

Дополнительные требования:
Добавить примеры с range()
```

После нажатия **«Сгенерировать с AI»** backend отправляет запрос AI API.

AI возвращает структурированный материал, который открывается в редакторе.

Преподаватель может:

- изменить текст;
- добавить собственный текст;
- удалить часть материала;
- вставить изображение;
- добавить код;
- добавить таблицу;
- использовать AI для редактирования отдельных фрагментов.

## 9. Создание теста по материалу

Одна из ключевых функций проекта.

После проведения занятия преподаватель открывает уже созданный материал и нажимает:

```text
Создать по материалу
```

Далее можно выбрать:

- Тест;
- Практическое задание;
- Контрольные вопросы;
- Домашнее задание.

Пример настроек:

```text
Материал:
Цикл for в Python

Количество вопросов: 10
Сложность: Средняя

Типы вопросов:
6 — один правильный ответ
2 — несколько правильных ответов
2 — открытый вопрос

Использовать только информацию из материала: Да
```

AI получает содержание конкретного материала. Таким образом тест создаётся не просто по названию темы, а именно по материалу, который преподаватель использовал на занятии.

## 10. Типы вопросов

## 15. Подключение студента

### Вариант 1. Ссылка

Преподаватель отправляет ссылку студентам.

Система уже знает:

- тест;
- группу;
- преподавателя;
- тестовую сессию.

Студент выбирает себя из списка группы.

### Вариант 2. Код подключения

Студент открывает страницу **«Присоединиться к тесту»**, вводит код, после чего система показывает нужную группу и список студентов.

## 17. Состояния тестовой сессии

### Waiting

Студенты подключаются, но отвечать ещё нельзя.

Преподаватель видит количество подключившихся.

### Active

Преподаватель нажимает **«Начать для всех»**.

У студентов открывается тест и запускается таймер.

Преподаватель видит:

```text
Подключено: 15
Выполняют: 12
Завершили: 3
```

### Finished

Преподаватель нажимает **«Завершить тестирование»**.

После этого:

- тест блокируется;
- все незавершённые ответы автоматически отправляются;
- студенты больше не могут изменять ответы;
- преподавателю показываются результаты.

Тест также может завершиться автоматически после окончания таймера.

## 18. Real-time работа

Для real-time взаимодействия используется **SignalR**.

Он позволит:

- мгновенно запускать тест для всех;
- завершать тест;
- обновлять количество подключённых студентов;
- отображать прогресс;
- показывать завершивших студентов;
- отправлять системные события.

```text
Teacher
   │
   │ Start Test
   ↓
ASP.NET Core + SignalR
   │
   ├── Student 1
   ├── Student 2
   ├── Student 3
   └── Student N
```

## 19. Мониторинг активности во время теста

Обычный браузер не позволяет полностью запретить Alt+Tab, переключение приложений, создание скриншотов или использование второго устройства.

Поэтому система реализует **мониторинг активности пользователя во время тестирования**, а не абсолютную защиту от списывания.

Можно отслеживать:

- переход на другую вкладку;
- потерю фокуса окна;
- выход из fullscreen;
- возвращение в окно;
- копирование текста;
- вставку текста;
- попытку закрытия страницы.

Пример журнала:

```text
14:31:02 — начал тест
14:34:18 — покинул вкладку
14:34:27 — вернулся
14:38:52 — вышел из fullscreen
14:39:01 — вернулся
14:44:13 — завершил тест
```

## 20. Проверка тестов

Открытые вопросы могут:

- проверяться преподавателем вручную;
- предварительно анализироваться AI.

AI может предложить оценку, но окончательное решение остаётся за преподавателем.

---

## 21. AI-проверка открытых ответов

Пример задания:

```text
Объясните разницу между циклом for и while.
```

AI может вернуть:

```text
Предварительная оценка: 8/10

Сильные стороны:
- правильно описан цикл for;
- правильно указано назначение while.

Недочёты:
- отсутствует пример;
- недостаточно подробно описано условие завершения.
```

Преподаватель может подтвердить или изменить оценку.

## 44. Позиционирование проекта

EduForge AI не является просто оболочкой над ChatGPT или другим AI API.

AI — это один из модулей системы.

Главная ценность проекта заключается в полном образовательном цикле:

```text
Создание материала
        ↓
Редактирование
        ↓
Проведение занятия
        ↓
Создание теста по материалу
        ↓
Проведение теста
        ↓
Получение результатов
        ↓
Аналитика
        ↓
AI-анализ
        ↓
Создание нового материала
```

Платформа объединяет:

- AI;
- LMS-функциональность;
- тестирование;
- группы;
- аналитику;
- библиотеку контента;
- редактор;
- real-time взаимодействие.

**«Разработка интеллектуальной веб-платформы для генерации, публикации и проведения учебных материалов с использованием технологий искусственного интеллекта»**

Название продукта:

**EduForge AI**

## 46. Итог

EduForge AI должен стать современной платформой для преподавателей, которая позволяет в одном месте:

- создавать материалы;
- использовать AI;
- проводить занятия;
- создавать тесты по пройденным материалам;
- проверять знания студентов;
- анализировать результаты;
- обмениваться готовыми материалами.

Основной акцент проекта:

**AI + удобство преподавателя + красивый современный интерфейс + полный цикл работы с учебным материалом.**
