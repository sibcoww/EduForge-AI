# EduForge AI

Интеллектуальная система автоматической генерации учебных и тестовых материалов. Помогает преподавателю подготовить урок, составить и проверить тест, организовать группы и провести тестирование онлайн.

## Возможности

- **Учебные материалы:** генерация по теме или выбранным фрагментам PDF, DOCX, TXT и Markdown; визуальный редактор, таблицы и подсветка кода.
- **Наглядные инструкции:** места для скриншотов, загрузка изображений, цветные стрелки и фигуры, подписи вручную или с помощью AI.
- **Тесты:** пять типов вопросов, общий балл и баллы за вопрос, учёт аудитории и пожеланий преподавателя.
- **Контролируемая генерация:** предложения учебных целей, цитаты и основания ответов, матрица покрытия и пересмотр вопросов после изменения урока. Результат проверяет преподаватель.
- **Группы и сессии:** приглашения студентов по ссылке, код подключения к тесту, таймер, автосохранение ответов, результаты и журнал событий.
- **Практические задания:** Python в изолированной Docker-среде, предпросмотр HTML/CSS, работы по дизайну и 3D с оценкой по рубрике.
- **Общая библиотека:** модерация, копирование материалов и тестов, обновление личных копий. Доступ — частный, по ссылке для вошедших преподавателей или публичный в библиотеке.
- **Аккаунты:** вход по email или Google, сохранение входа, восстановление через SMTP, профиль с дисциплинами и рекомендации.
- **История генераций:** параметры, исходный результат, экспертные оценки и экспорт CSV для сравнительного исследования.

## Стек

| Часть | Технологии |
|---|---|
| Интерфейс | Next.js 16, React 19, TypeScript, TipTap, Three.js |
| Сервер | C# / .NET 10, ASP.NET Core, Entity Framework Core, SignalR |
| База данных | PostgreSQL 17, миграции EF Core |
| Интеграции | OpenAI Responses API, Google OAuth, SMTP |
| Изоляция кода | Docker |
| Проверки | xUnit, интеграционные тесты API, Node.js tests, браузерные сценарии Playwright |

## Структура и документация

- `frontend/eduforge-web` — интерфейс; `backend` — API, бизнес-логика и тесты.
- [TESTING.md](TESTING.md) — локальный запуск, настройки и сценарии проверки.
- [ROADMAP.md](ROADMAP.md) — выполненные функции и дальнейшие задачи.
- [SMTP_SETUP.md](SMTP_SETUP.md) — восстановление пароля и настройка почты.
- [DESIGN.md](DESIGN.md) и [UX-CONTRACT.md](UX-CONTRACT.md) — оформление и правила взаимодействия.
- [experiments](experiments/README.md) — подготовка сравнительного пилота для диплома.

Для локального запуска нужны .NET 10, Node.js и PostgreSQL. Docker Desktop используется для базы через Compose и запуска Python-заданий. Настройки перечислены в [backend/.env.example](backend/EduForge.Api/.env.example) и [frontend/.env.example](frontend/eduforge-web/.env.example); `.NET` не загружает `.env` автоматически. Ключи, локальные настройки и резервные копии не хранятся в Git.

Проект развивается. Технические проверки не заменяют экспертную оценку AI-материалов и исследовательский эксперимент.
