# EduForge AI

Платформа для преподавателей: создание учебных материалов и тестов с помощью AI, управление группами и проведение тестирования онлайн.

## Возможности

- Создание и редактирование материалов в визуальном редакторе.
- Генерация материалов и тестов по содержанию урока с помощью OpenAI.
- Пять типов вопросов, настройка общего балла и баллов за каждый вопрос.
- Группы и списки студентов.
- Тестовые сессии с кодом подключения, таймером, автосохранением ответов и результатами.
- Общая библиотека: публикация и копирование материалов и тестов.
- Вход по email и паролю или через Google, управление аккаунтами для администратора.

## Стек

**Frontend:** Next.js 16, React 19, TypeScript, TipTap.

**Backend:** C# / .NET 10, ASP.NET Core, Entity Framework Core, SignalR.

**База данных:** PostgreSQL 17, Docker Compose.

**Интеграции:** OpenAI Responses API, Google OAuth.

**Тестирование:** xUnit и интеграционные тесты API.

## Структура

- `frontend/eduforge-web` — веб-интерфейс.
- `backend` — API, бизнес-логика, работа с базой и тесты.
- `docker-compose.yml` — локальная база PostgreSQL.

Проект находится в активной разработке. Для локального запуска нужны .NET 10, Node.js и PostgreSQL. Настройки окружения описаны в `.env.example`; ключи и локальные настройки не хранятся в репозитории.
